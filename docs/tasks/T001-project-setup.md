# T001 — Set up the app and developer workflow

**Goal:** Create the React/TypeScript/Vite frontend and Fastify/TypeScript backend in one project.

**Scope:** Add Tailwind, standard shadcn/ui components, Biome, Lefthook, Vitest, and local development commands. Configure Vite-to-Fastify API proxying and production serving of the frontend build. Follow `AGENTS.md`; use the project Fastify skill only as guidance.

**Dependencies:** None.

**Done when:** The app starts locally; formatting/lint, type checks, and unit tests have runnable commands; the production build succeeds.
